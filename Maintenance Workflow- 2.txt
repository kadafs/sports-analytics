Calibration is handled by 

calibrate_league.py NOW python calibrate_from_local.py
 and can happen in two contexts:

1. Automatic (During Prediction Runs)
In 

run_basketball_daily.py
, when processing a league without an existing config, the script auto-calibrates on the fly:

run_basketball_daily.py → detects no configs/leagues/{id}.json
                        → calls calibrate_league.auto_calibrate(league_id)
                        → fetches finished games from API
                        → derives pace_pivot, eff_pivot, hca, regression_factor
                        → writes configs/leagues/{id}.json
                        → continues with prediction
You can skip this with --no_calibrate to only use existing configs.

2. Manual (Maintenance)
Run directly to recalibrate one or all leagues:

bash
python calibrate_league.py --league_id 40      # Recalibrate BBL Germany
python calibrate_league.py --all                # Recalibrate all leagues
What Calibration Actually Does
Fetches all finished games this season for the league from the API
Computes avg_total (mean game total) and std_total (variance)
Derives HCA from mean home margin, clamped to 0.5–8.0
Uses the tier's pace as pace_pivot (e.g., 78 for top_domestic)
Back-derives eff_pivot = (avg_total × 100) / (2 × pace_pivot) — this is the Fix 9 formula that ensures dimensional consistency with the engine
Sets regression_factor based on sample size (more games → higher trust, capped at 0.96)
Writes the config to configs/leagues/{id}.json
When Should You Recalibrate?
Start of season — When new leagues begin and have 15+ games
If MAE drifts — Run python backtest_v4.py and if accuracy drops, recalibrate
After league breaks — Mid-season breaks can shift team dynamics
Never during playoffs — Small sample + different play style would corrupt calibration
The calibration is essentially answering: "What does a typical game in this league look like?" — and the engine then adjusts from that baseline based on each specific matchup.

## Glossary of Audit Metrics

### `Δ` — Absolute Delta *(per game, in the game log)*
> **"How far off was the model, regardless of direction?"**

```
Δ = |Actual Game Total − Model Projected Total|
```
Always a positive number. A Δ of `8.0` means the model was 8 points off — whether the game went higher or lower than projected. This is what drives the **Tier** (BULLSEYE/SOLID/BUST etc).

---

### `±Δ` — Signed Delta *(per game, in the game log)*
> **"Which way did the model miss?"**

```
±Δ = Actual Game Total − Model Projected Total
```
- **`+8.0` (green)** → game scored **8 more points** than the model expected *(game went OVER)*
- **`−8.0` (red)** → game scored **8 fewer points** than the model expected *(game went UNDER)*

Same magnitude as `Δ`, but tells you the direction of the error.

---

### `AVG Δ` — Average Absolute Delta *(league breakdown)*
> **"On average, how many points does the model miss by in this league?"**

The mean of all `Δ` values for a league. Lower is better. This is your **accuracy score** for the league — equivalent to MAPE but in raw points.

| AVG Δ | Meaning |
|---|---|
| ≤ 8.5 | 🟢 Very accurate |
| ≤ 14.5 | 🟡 Respectable |
| > 14.5 | 🔴 Struggling |

---

### `SIGNED Δ` — Average Signed Delta *(league breakdown)*
> **"Does the model consistently overshoot or undershoot this league?"**

The mean of all `±Δ` values for a league. This reveals **systematic bias**:

- **`+4.2` (red)** → model consistently underestimates scoring in this league — games tend to go **Over** the model's projection
- **`−4.2` (green)** → model consistently overestimates scoring — games tend to go **Under** the model's projection
- **Near 0** → no systematic bias, errors are random noise

---

### `BIAS` *(league breakdown)*
> **"Plain-English label for the signed delta direction"**

| BIAS | Signed Δ | Meaning |
|---|---|---|
| 📈 Over | < −3 | Model overshoots — back Unders in this league |
| 📉 Under | > +3 | Model undershoots — back Overs in this league |
| ✅ Neutral | −3 to +3 | No significant directional lean |

The threshold of ±3 points is deliberate — anything smaller is statistical noise for basketball games averaging 150+ points.
